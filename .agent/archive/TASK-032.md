## 요청

## 설계

- `TranslationTranscript`(TranslateCore, 테스트): 렌즈가 번역해 보여준 글을 나온 순서대로 모은다
  - 같은 원문(대소문자·문장부호·공백 무시, 언어별)은 한 번만. 자동 생성 자막처럼 바로 앞 기록의 원문 뒤에 글이 이어 붙은 것이면
    앞 기록을 바꾼다(단어마다 기록이 쌓이지 않게). 앞 기록 원문의 앞부분만 다시 보이면 넘긴다
  - 최근 300개까지. 복사용 글(번역을 줄바꿈으로 이음)
  - 메모리에만 두고 렌즈를 닫으면 사라진다 (파일로 저장하지 않음)
- 렌즈: 원문과 맞는 번역(이어 보여주기·생성 중 글 제외)을 보여줄 때 기록한다
- 화면: 도구 막대에 "번역 기록" 켜기/끄기 버튼. 켜면 렌즈 옆 패널(너비 320)에 기록을 보여주고 새 기록이 오면 맨 아래로 따라간다.
  머리글에 전체 복사·닫기. 켜기/끄기는 기억한다(UserDefaults `TranscriptVisible`)
  - 위치(`LensGeometry.transcriptFrame`, 테스트): 렌즈 오른쪽 → 공간이 없으면 왼쪽 → 둘 다 없으면 화면 오른쪽 안쪽.
    아래는 렌즈 아래와 맞추고 위로 렌즈 높이(최소 260)만큼, 화면 안으로 자른다 (자막 렌즈는 얇으므로 영상 옆으로 올라간다)
  - 렌즈를 옮기거나 크기를 바꾸면 따라간다
