# TASK-072: 화면 일부가 바뀌면 그 자리 번역만 숨기기, 포인터가 렌즈 위에서 움직이는 동안 자주 찍기

- 상태: COMPLETED
- 생성일: 2026-11-04

## 요청

사용자(화면 기록 첨부): "웹사이트에서 메뉴에 마우스오버할때마다 새로 그리는데 이거 해결할 방법이 있나" → 원인·방법 설명 뒤
"1과 2를 한 작업으로 먼저, 3은 따로" 추천에 "어 진행해".

화면 기록(웹페이지 위 렌즈, 상단 메뉴에 마우스를 올려 드롭다운이 열림)에서 본 것:
- 메뉴가 열리면 렌즈 전체 번역이 사라져 원문이 보였다가 전체를 다시 그린다. 메뉴와 상관없는 아래 제목도 깜빡인다
- 메뉴가 열린 직후 지난 번역이 메뉴 위를 덮고, 닫힌 직후 메뉴 번역이 페이지 위에 떠 있다

원인: `ChangeTracker`는 처리한 화면과 64×64 지문 평균 차이가 `movedAwayThreshold`(0.005)를 넘으면 스크롤처럼
`movedAway`로 보고, 렌즈는 번역을 모두 숨긴다(`isOutdated`). 드롭다운처럼 일부만 크게 바뀌어도 넘는다.
화면이 그대로일 때는 0.5초마다 찍어 메뉴가 열리고 닫힌 것을 늦게 안다.

## 요구사항

1. 스크롤 이벤트가 아닌 화면 변화로 `movedAway`가 되면, 처리한 화면과 달라진 곳에 걸친 문단만 숨기고 나머지 번역은 그대로 둔다
2. 포인터가 렌즈 위에서 움직이거나 클릭한 뒤 잠시 동안은 화면이 그대로여도 바뀌는 중일 때 간격(0.15초)으로 찍는다

## 설계

- `ImageFingerprint.changedArea(since:)` → `ChangedArea`: 지문 픽셀마다 밝기 차이가 기준 이상인지. `intersects(_:in:)`로
  이미지 픽셀 영역(문단 상자)이 바뀐 곳에 걸치는지 본다
- `ChangeTracker.changedArea`: `movedAway`일 때 처리한 화면과 달라진 곳 (처리한 화면이 없으면 nil = 전체)
- 렌즈: `LensModel.hiddenParagraphIDs`. `movedAway`에서 바뀐 곳에 걸친 문단만 넣고, 바뀐 곳을 모르면 지금처럼 전부 숨긴다.
  화면이 처리한 화면으로 돌아오거나(`unchanged`) 다시 인식하면 비운다. 스크롤·이동·일시정지는 지금처럼 전부 숨긴다
- `CaptureSchedule.delay`에 마지막 포인터 동작을 더한다. 렌즈 안 `mouseMoved`(전역 모니터, 권한 불필요)·클릭
- 전체 평균 차이 기준(`movedAwayThreshold`)은 그대로: 작은 변화(호버 강조)는 지금처럼 숨기지 않는다
