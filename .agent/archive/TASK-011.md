# TASK-011: 스크롤하면 지난 번역을 바로 숨김

- 상태: COMPLETED
- 생성일: 2026-10-30

## 요청

사용자: "잘되 그리고 스크롤 후 번역한거 바로 사라지게 해줘". 지금은 스크롤해도 화면이 멈추고 다시 인식할 때까지(0.5~1초 이상)
지난 번역이 원래 자리에 남아, 이미 지나간 문단의 번역이 다른 내용 위에 겹쳐 보인다.

## 설계

- 번역 숨김 상태(`LensModel.isOutdated`): 켜지면 렌즈 본체에 번역·안내 문구를 그리지 않아 페이지가 그대로 보인다
- 숨기는 때
  1. 렌즈 위에서 마우스·트랙패드 스크롤 이벤트가 오면 바로 (전역 스크롤 모니터. 마우스 이벤트 모니터는 권한이 필요 없다.
     키 이벤트만 손쉬운 사용 권한이 필요하다)
  2. 캡처 화면이 마지막으로 처리한 화면에서 크게 벗어나면 (키보드 스크롤·페이지 이동 등).
     단어 하나 바뀐 정도로는 숨기지 않는다 (움직이는 광고 등이 있어도 번역이 계속 보이게)
  3. 렌즈를 옮기거나 크기를 바꾸는 동안 (지난 번역이 다른 내용 위로 같이 움직이므로)
- 다시 보이는 때
  - 화면이 멈춰 다시 인식하면 (기억한 번역은 바로, 새 문단은 번역되는 대로)
  - 스크롤했지만 화면이 그대로면(페이지 끝 등) 스크롤이 멈춘 뒤 바로
  - 인식하는 사이에 또 스크롤했으면 다음 화면을 기다린다
- `ChangeTracker.observe`: 프레임마다 `unchanged`(처리한 화면과 거의 같음) / `movedAway`(크게 벗어남) / `settled`(바뀐 뒤 멈춤 →
  처리)를 돌려준다. `movedAwayThreshold`는 측정값 사이(단어 변경 0.0010 < 기준 < 4px 스크롤 0.018)

## 요구사항

1. `ChangeTracker.observe` + 테스트 (기존 `shouldProcess` 대체)
2. 앱: 숨김 상태, 스크롤 모니터(렌즈를 닫으면 해제), 캡처 루프·이동·크기 조절 연결
3. `AGENTS.md` 갱신

범위 밖: 캡처 주기·인식 속도 변경, 번역 엔진 변경
