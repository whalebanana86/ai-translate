## 원인 분석 (사용자 스크린샷을 OCR해 재현)

1. 위치가 밀림
   - 배너 문장 아래의 링크 "Get help"가 문장의 다음 줄로 묶였다 (가로로 겹치고 간격이 가까움). 같은 줄에 "Show details"가 나란히
     있는데도 문단으로 이었다.
   - 오른쪽 이웃 판정이 문단 자기 영역 안에 있는 블록("Get help", x=279 < 문단 오른쪽 끝 1115)까지 이웃으로 봐서
     문단 너비가 약 85pt로 줄었다 → 번역이 한 줄에 한두 단어씩 10줄로 길어짐.
   - 길어진 문단 때문에 겹침 밀기(`stackedTops`)가 제목·단 제목을 차례로 아래로 밀어 렌즈 밖으로 나갔다.
2. 흰 바탕
   - 원문 글자를 가리려면 바탕은 필요하다 (TASK-008: 바탕 없이 겹치면 두 글자가 겹쳐 읽기 어려움).
   - 하지만 흰색일 필요는 없다. 어두운 페이지에서 흰 상자가 튀고, 반투명 막 때문에 페이지 색도 바뀐다.

## 설계

- 위치: 모든 문단을 원문 위치(왼쪽 위)에 그대로 둔다. 밀지 않는다(`stackedTops` 제거)
  - 너비: 여러 줄 문단은 원문 너비. 한 줄 문단(제목·버튼)은 오른쪽 이웃(문단 오른쪽 끝보다 오른쪽에서 시작하는 블록) 앞이나
    렌즈 끝까지
  - 높이: 아래 블록(가로로 겹치는 블록 중 아래에서 시작하는 것) 앞이나 렌즈 아래 끝까지 쓸 수 있다.
    그래도 넘치면 글자를 줄여 맞춘다 (`minimumScaleFactor`)
- 묶기: 같은 줄 높이에 다른 글줄이 나란히 있고, 그 글줄이 문단 가로 범위 안에 있으면 이 줄은 문단의 다음 줄이 아니라
  링크·버튼 줄로 보고 잇지 않는다
- 색: 캡처 이미지에서 문단 영역의 바탕색(가장 많은 색)과 글자색(바탕과 가장 다른 색 중 가장 많은 색)을 뽑아
  번역 바탕과 글자에 쓴다. 대비가 너무 낮으면 바탕 밝기에 따라 검정/흰색 글자
- 반투명 막은 없앤다: 번역이 페이지 색으로 원래 자리에 그려지므로 페이지가 그대로 보이고 위치를 바로 알 수 있다.
  번역되지 않은 문단·번역 불필요 문단은 그리지 않아 원문이 그대로 보인다. 렌즈 범위는 테두리로 표시
- 본체 창 그림자 끔 (투명 창이라 번역 문단마다 그림자가 생긴다)

## 요구사항

1. `TextBlockGrouper`: 같은 줄 높이 나란한 글줄 규칙 + 테스트
2. `LensGeometry.paragraphFrames`: 원문 위치·너비 규칙·최대 높이 + 테스트. `stackedTops`·최소 너비 제거(테스트 포함, 동작 제거에 따름)
3. `BlockColors`(새 파일): 바탕색·글자색 추출 + 그린 이미지 테스트
4. 앱: 렌즈 본체(막 없음, 페이지 색, 맞춤 축소, 번역된 문단만), `LensSession`(색 추출, 렌즈 크기, 그림자)
5. 사용자 스크린샷 두 장(어두운 페이지, X 타임라인) 위 합성 렌더링으로 확인
6. `AGENTS.md` 갱신

범위 밖: 번역 엔진 변경(로컬 LLM·Apple 번역 비교는 별도 TASK 제안), 글자 크기 계산 방식 변경
