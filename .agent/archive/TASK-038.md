# TASK-038: 자막 번역이 조금씩 흔들리는 문제

- 상태: COMPLETED
- 생성일: 2026-11-02

## 요청

사용자: "이거 영상찍은건데 번역창 위치가 조금씩 움직이는데 봐봐" (화면 기록 34.7초, 유튜브 TED 자막 위 렌즈)

## 분석 (화면 기록을 초당 10장으로 잘라 번역 글(흰 글자) 영역을 잼)

- 같은 자막인데 글 너비가 양쪽으로 ±6~8px 바뀌었다 늘었다 함(6.5↔6.8초, 21.5↔21.8초, 22.1↔22.7초): 프레임을 비교하니 같은 번역의
  글자 크기가 바뀜. 글자 크기를 인식한 원문 줄 높이에서 정하는데(`LensGeometry.fontSize`), 인식할 때마다 줄 높이가 조금씩 다르다
- 같은 자막에서 위아래·좌우로 3~9px 이동(2.9초, 26.5~27.1초, 33.2~33.8초): 번역 자리를 매번 인식한 상자의 가운데·아래 끝에 맞추는데,
  상자 가장자리가 인식마다 조금씩 다르고 아래로 내려가는 글자(g, y, p)가 있는 문장은 아래 끝이 더 내려간다
- 덧붙여 발견: 자막 사이 빈 구간에 "렌즈 안에서 텍스트를 찾지 못했습니다." 안내가 영상 한가운데 뜸(24.0초)

## 설계

- `CaptionDetector`가 자막마다 자리(`CaptionAnchor`: 가운데 x, 아래 끝, 줄 높이)를 돌려준다. 기억한 자리와 가운데·아래 끝 차이가
  줄 높이의 0.35배 이하면 기억한 값을 그대로 쓰고, 넘으면(자막이 실제로 옮겨감) 새 값으로 바꾼다. 줄 높이는 0.75~1.25배 안이면
  그대로 (아래로 내려가는 글자 차이 약 20%는 흡수, 전체 화면 전환 같은 실제 크기 변화만 반영)
- 배치: 자막 번역은 기억한 자리의 가운데·아래 끝, 글자 크기는 기억한 줄 높이로
- 원문 가림 상자: 원문 상자와 번역 글 영역을 모두 덮는 사각형(+여백)으로 그린다. 번역을 기억한 자리에 그려도 이번에 인식한 원문
  글자가 삐져나오지 않는다 (보통 문단은 지금과 같은 모양)
- 영상(계속 바뀌는 화면)을 보는 동안에는 "텍스트를 찾지 못했습니다" 안내를 띄우지 않는다
