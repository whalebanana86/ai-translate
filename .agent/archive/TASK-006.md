# TASK-006: OCR 잡음 제거와 줄바꿈 유지

- 상태: COMPLETED

## 요청

첫 실제 사용 결과(X 타임라인 스크린샷)에서 아이콘이 글자로 인식되고(`• I`, `0 1`, `ıhl 120`), 버튼(`G...`)이 본문 앞에 붙고,
목록형 트윗의 줄이 한 문장으로 합쳐졌다. 이어질 번역 렌즈(TASK-007)는 계속 다시 인식하므로 먼저 품질을 잡는다.

## 사전 확인 (사용자 스크린샷을 스크래치에서 OCR, 저장소에는 넣지 않음)

- 아이콘 잡음: `企`·`贝` 신뢰도 0.30, `• 1`·`ıll 120` 0.50. 실제 본문은 모두 1.00
- 버튼: `...`, `G...` 신뢰도 1.00. `G...`(x=1082)가 아래 본문 줄과 가로로 겹쳐 같은 문단으로 묶임
- 목록 트윗 8줄이 공백으로 이어져 한 문장이 됨 (줄 너비 176~812px, 짧은 줄이 강제 줄바꿈)
- "5시간"이 `51|Zł`로 오인식. 자동 감지 끔 + ko-KR 우선이면 정확하지만 그 설정은 일본어 줄이 빠지므로(TASK-003)
  자동 감지 유지. 원문 언어 지정 옵션은 후속 후보

## 요구사항

1. 잡음 줄 제거: 신뢰도 0.6 미만이면서 글자(`Character.isLetter`)가 4개 미만인 줄은 버린다
2. 글자가 2개 미만인 줄(`...`, `G...`, `$19`, `120`)은 다른 줄과 묶지 않고 단독 문단으로 둔다
3. `TextBlock.isTranslatable`: 글자 2개 이상. `RegionTranslator.translate`는 번역 가능한 문단만 엔진에 보내고,
   나머지는 원문을 그대로 번역 결과로 쓴다 (렌즈에서 가격·숫자가 사라지지 않게). 번역 가능한 문단이 없으면 엔진을 부르지 않는다
4. 줄바꿈 유지: 다음 줄의 첫 단어(CJK는 첫 글자)가 앞줄 끝 뒤의 남은 공간(문단 오른쪽 끝 기준)에 들어갔다면
   강제 줄바꿈으로 보고 `\n`으로 잇는다. 아니면 기존 규칙(공백 또는 CJK 붙임)
5. 시스템 프롬프트에 세그먼트 안의 줄바꿈을 유지하라는 지시 추가. 라이브로 줄바꿈 유지 확인
6. 테스트: 잡음 제거, 단독 문단, 번역 대상 선별, 줄바꿈 판단(스크린샷의 줄 너비를 본뜬 합성 데이터)

범위 밖: 원문 언어 지정, 렌즈(TASK-007)
