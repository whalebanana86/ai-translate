# TASK-034: 자막이 다 나온 뒤 번역

- 상태: COMPLETED
- 생성일: 2026-11-02

## 요청

사용자: "영상자막인 경우 자막이 나오는 중간중간 번역하는데 자막이 다 나온다음 번역을 할 수 있나?"

## 원인

자동 생성 자막은 단어가 하나씩 붙는다. 계속 바뀌는 화면에서는 0.25초마다 다시 인식하고 새 글이면 바로 번역하므로 문장 조각을 번역한다.

## 설계

- `TextSettling`(TranslateCore, 테스트): 계속 바뀌는 화면에서만 쓴다
  - 인식할 때마다 보이는 문단 글과 처음 보인 때를 기억한다 (보이지 않게 된 글은 잊는다)
  - 번역할 문단: 글이 `settleTime`(0.5초) 넘게 그대로인 문단만. 다 나온 문단이 없는데 기다린 지 `maxWait`(2초)가 지나면
    말이 쉬지 않고 이어지는 것으로 보고 그때까지 나온 글을 보낸다
- 렌즈: 계속 바뀌는 화면이면 `translateIfNeeded`에서 다 나온 문단만 보낸다. 기다리는 동안은 같은 자리의 지난 번역을 이어 보여준다
  - 이어 보여주기 시간 2초 → 3초 (기다림 최대 2초 + 번역 약 0.35초 동안 원문이 드러나지 않게)
- 대가: 한 번에 나오는 자막(직접 올린 자막)도 0.5~0.7초 늦게 번역된다 (인식 주기 약 0.35초 단위로 확인)

- [x] AC2. 계속 늘어나는 글은 2초마다 그때까지 나온 글을 고른다, 보낸 뒤 다시 기다린다 (테스트).
- [x] AC3. 사라졌다 다시 보인 글은 처음부터 잰다 (테스트). 이어 보여주기 3초 (테스트 갱신).
