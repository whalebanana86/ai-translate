- 단계: 캡처 주기 → 화면 캡처(ScreenCaptureKit, 매번 공유 가능 콘텐츠 조회) → 지문·변화 판단 → (멈춤 대기) → 엔진 준비 →
  OCR(Vision accurate) → 문단 묶기 → 색 추출 → 배치·그리기 → 번역(엔진) → 기억·다시 그리기
- 측정 1 (화면 밖, 스크래치): 스크린샷 두 장으로 지문·OCR(accurate/fast, 언어 교정 유무)·묶기·색·배치, 5회 중앙값
- 측정 2 (앱): `LensSession`에 단계별 시간 기록(`Logger`, info 단계, 숫자·엔진 이름만. 글 내용은 남기지 않음 — AGENTS.md 개인정보).
  사용자가 렌즈를 쓰는 동안 `log stream`으로 모아 캡처 시간과 체감 시간(화면이 바뀌기 시작해서 번역이 다시 보이기까지)을 잰다
- 개선 방안은 측정 근거와 함께 제안하고, 구현은 사용자 결정 후
