# TASK-047: 번역을 기다리는 문단의 원문 가리기

- 상태: COMPLETED

## 요청

사용자: "번역할때 원문을 블라인드처리해서 그 위에 번역이 나오게 해줘"

## 현재

번역 전 문단은 그리지 않아 원문이 그대로 보이다가 번역이 나오면 바뀐다(로컬 엔진은 위에서부터 한 문단씩이라 아래 문단은 2초 넘게
원문으로 보인다). 번역이 나온 문단만 원문 바탕색 상자로 가리고 그 위에 번역을 그린다.

## 설계

- 번역을 기다리는 문단(`.pending`)도 원문 바탕색 상자로 가리고, 원문 줄마다 흐린 막대(글자색 18%)를 그려 번역 중임을 보인다.
  번역이 생성되기 시작하면 같은 상자 위에 번역 글이 나온다
- 번역이 올 수 없으면 가리지 않는다: 번역·엔진·인식 실패(`.failed`) 때는 원문을 보인다. 일시정지·스크롤·이동 중은 지금처럼
  아무것도 그리지 않는다. 숫자·버튼·이미 대상 언어인 문단(`.original`)은 가리지 않는다
- 판단은 `BlockContent.hidesOriginal(canTranslate:)`(TranslateCore, 테스트)

## 완료 조건 (Acceptance Criteria)

- [x] AC2. 렌즈: 기다리는 문단은 바탕색 상자 + 줄 막대, 생성 중·번역된 문단은 같은 상자 위에 번역. 화면 밖 렌더링으로 확인
  (보통 문단·자막).
