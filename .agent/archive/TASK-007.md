# TASK-007: 번역 렌즈 (계속 떠 있는 창, 창 안에 덮어쓰기)

- 상태: COMPLETED
- 생성일: 2026-10-30

## 요청

사용자: "창이 계속 떠있어서 그 창안에 들어오면 무조건 번역되는거였어". 결정(사용자 선택):
- 번역 표시: **창 안에 덮어쓰기(렌즈)**. 창이 원문 위를 덮고 그 자리에 번역을 보여준다. 원문은 버튼으로 잠깐 본다.
  스크롤은 아래 페이지로 전달된다
- **⌘⇧1 드래그로 만든 영역이 계속 떠 있는 렌즈가 된다**. 일회성 결과창은 없앤다

## 설계

- 창 세 개 (모두 앱을 활성화하지 않는 패널, 모든 Space·전체화면 위)
  - 렌즈 본체: 선택 영역 크기, 마우스 통과(클릭·스크롤은 아래 페이지로), 원문을 가리는 배경 위에 번역을 원래 문단 위치에 그림
  - 도구 막대: 렌즈 위쪽(공간이 없으면 렌즈 안 위쪽). 끌어서 이동, 진행 표시, 언어 선택, 원문 보기(본체 잠시 숨김), 복사, 닫기
  - 크기 조절 손잡이: 렌즈 오른쪽 아래 모서리, 끌어서 크기 조절(왼쪽 위 고정, 최소 크기)
- 감시 루프: 0.5초마다 렌즈 영역 캡처(이 앱 창은 캡처에서 빠지므로 렌즈 아래 원문이 찍힘) →
  축소 지문(`ImageFingerprint`)으로 변화 감지 → 바뀐 뒤 한 번 멈췄을 때만(`ChangeTracker`) OCR → 문단
- 번역 기억(`TranslationMemory`): (원문, 언어) → 번역. 스크롤해도 이미 번역한 문단은 엔진을 다시 부르지 않고,
  새 문단만 한 번에 보낸다. 번역 요청은 동시에 하나만, 끝나면 남은 문단을 이어서 보낸다. 오류는 다음 변화 때 다시 시도
- 아직 번역 안 된 문단은 원문을 흐리게 보여주고, 번역할 필요 없는 문단(숫자·버튼)은 원문 그대로
- 문단 배치(`LensGeometry`): 원래 위치(이미지 픽셀 ÷ 화면 배율)에 두되, 번역이 길어 겹치면 아래로 민다.
  글자 크기는 원래 줄 높이에 맞춘다(11~24pt)
- 이동·크기 조절 중에는 캡처를 멈추고, 끝나면 변화 감지를 초기화한다
