# TASK-052: 이모지는 번역하지 않고 그대로 보이기

## 요청

사용자: "이모지는 번역에서 제외해" → 확인 질문 답(여러 개): "이모지가 이상한 글자로 번역됨, 문장이 이모지에서 끊김, 번역이 이모지를 가림"

## 원인 (그린 화면 + Vision 측정, 하네스는 저장소 밖)

- Vision은 이모지를 글자로 읽지 못한다. 대부분 빼고 읽지만 엉뚱한 글자로 읽기도 한다: 🎉🎉🎉 → "it"·"然", 🤡 → "®", 🚀 → "*",
  ☀️ → "*". 이 글자가 번역에 들어간다
- 문장 중간 이모지에서 OCR 줄이 둘로 나뉘기도 한다("오늘 날씨 좋다 😊 산책 가자" → "오늘 날씨 좋다", "산책 가자") → 따로 번역
- 이모지는 OCR 줄 영역 밖이거나 안이어도 글로 남지 않아, 번역 상자가 덮으면 사라진다

## 설계

- `EmojiFinder`(TranslateCore): OCR 줄과 같은 높이 띠에서 색 있는 덩어리(채도 높은 열이 줄 높이 0.4배 넘게 이어짐, 띠 밖으로 크게
  넘치지 않음: 프로필 사진 제외)를 찾는다. 진짜 단어 영역과 겹치는 덩어리는 색 글자(파란 링크 등)로 보고 뺀다
  - 단어 영역: Vision `boundingBox(for:)`로 공백 단위 단어마다 영역(`RecognizedLine.wordBoxes`)
  - 이모지 자리를 잘못 읽은 글자: 덩어리와 겹치고, 글자가 없거나(®, *) / 다른 문자(영어 줄의 然) / 두 글자 이하이면서 덩어리 색이
    여러 가지(퍼짐 0.25 이상: 파란 "Al"과 🎉 "it" 구분, 측정 0.00 대 0.42) → 뺀다
  - 이모지 자리에 표시(🟦, OCR이 내놓지 않는 문자. 로컬 모델이 번역 뒤에도 남김 36/36)를 넣는다: 줄 안이면 그 자리, 같은 줄 높이의
    두 OCR 줄 사이(양쪽 간격 줄 높이 1.5배 안)면 두 줄을 이어 한 줄로, 줄 끝·앞 1.5배 안이면 붙인다. 표시마다 이모지 영역을
    `RecognizedLine.emojis`에 둔다
- 렌즈: 표시 자리마다 캡처에서 오린 이모지 그림을 번역 글 안에 그린다(글자 크기에 맞춤). 번역에서 표시가 빠지면 남은 이모지를 끝에
  붙인다. 번역 기록·복사에서는 표시를 지운다. 오린 그림은 메모리에만 둔다
