# TASK-008: 렌즈 반투명 (아래 페이지 위치가 보이게)

- 상태: COMPLETED

## 요청

사용자: "반투명하게 해서 현재 위치가 어디인지 알 수 있게 해줘". 지금은 렌즈 본체 배경이 불투명해서 아래 페이지가 전혀
보이지 않아, 스크롤할 때 페이지의 어디를 보고 있는지 알 수 없다.

## 설계

- 렌즈 본체 배경을 반투명하게 해서 아래 페이지(이미지, 레이아웃, 여백)가 흐리게 보이게 한다
- 그대로 반투명만 하면 번역 글자와 그 아래 원문 글자가 겹쳐 읽기 어렵다 → 번역된 문단은 원문 자리를 거의 불투명한
  배경으로 가린다. 가리는 크기는 원문 문단 크기와 번역 글 크기 중 큰 쪽 (번역이 짧아도 원문 끝이 비치지 않게)
- 아직 번역되지 않은 문단은 그리지 않는다. 반투명 배경 너머로 원문이 흐리게 보이므로 "아직 번역 전"이 드러나고,
  OCR 글자를 원문 위에 다시 그려 이중으로 보이는 것을 막는다
- "인식하는 중…", "텍스트를 찾지 못했습니다" 문구는 아래 페이지 위에서도 읽히게 자체 배경을 둔다
- `ParagraphFrame`에 원문 문단 크기(`sourceSize`, 포인트)를 넣어 테스트한다

## 요구사항

1. `LensGeometry.paragraphFrames`가 원문 문단 크기를 함께 돌려준다 + 테스트
2. `LensBodyView`: 반투명 본체 배경, 번역 문단 가림 배경, 대기 문단 미표시, 안내 문구 배경
3. 실제 스크린샷 위에 렌즈를 합성한 렌더링으로 확인 (번역됨·대기·인식 중)
4. `AGENTS.md` 갱신

범위 밖: 투명도 조절 설정, 도구 막대·손잡이 모양 변경
