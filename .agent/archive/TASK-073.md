# TASK-073: 메뉴에 가려 잘린 문단 조각은 번역하지 않기

- 상태: COMPLETED
- 생성일: 2026-11-04

## 요청

TASK-072와 같은 사용자 보고(웹페이지 메뉴에 포인터를 올릴 때마다 렌즈가 새로 그림)의 셋째 방법. "1과 2를 한 작업으로 먼저,
3은 따로" 추천에 "어 진행해".

화면 기록에서 본 것: 드롭다운 메뉴가 제목 일부를 덮으면 OCR이 보이는 조각만 읽는다("Search API for agents From $4 /1k
requests" → "Search AF From $4 /", "Talk to sales" → "Talk to si", 지어낸 페이지 재현 TASK-072). 조각을 새 문단으로 번역해
번역을 기다리는 줄 막대가 뜨고, "API 검색, $4k 부터 시작", "s와 이야기해 보세요"처럼 엉뚱하게 번역되며, 번역 글이 문단 너비만큼
그려져 메뉴 위로 넘쳤다.

## 요구사항

- 바로 전에 읽은 문단과 같은 자리에서 줄 일부가 잘려(가로로 가려져) 글이 짧아진 문단은 번역하지 않고 원문 그대로 둔다
- 메뉴가 열려 있는 동안 다시 인식해도(메뉴 안 호버 등) 계속 조각으로 본다
- 메뉴가 닫혀 원래 문단이 다시 보이면 평소대로 번역한다(번역 기억이 있으면 바로)
- 영상(계속 바뀌는 화면)에서는 쓰지 않는다

## 설계

- `OccludedParagraphs.find(in:reference:)`: 새 문단의 모든 줄이 참고 문단 줄과 같은 자리(세로로 겹치고 왼쪽 또는 오른쪽 끝이
  맞음)이고, 적어도 한 줄이 잘렸으면(폭이 줄고, 글이 짧고, 잘린 쪽 반대편부터 글이 같음. 잘린 끝 두 글자는 OCR이 반쪽 글자를
  다르게 읽으므로 비교하지 않음) 조각. 같은 문단이 여러 문단으로 나뉘어 읽힌 경우 나머지 온전한 줄 문단도 조각
- 말줄임("…")으로 끝나는 줄은 잘린 것으로 보지 않는다(줄 수 제한 글). 글이 같은 줄바꿈 변화는 글이 짧아지지 않아 해당 없음
- 렌즈: 참고 문단 = 지난 인식 문단 + 계속 가려진 원래 문단. 조각은 문단 목록에서 뺀다(그리지도 번역하지도 않음)
